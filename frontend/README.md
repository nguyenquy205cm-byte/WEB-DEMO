# Frontend React

## Mục đích
Ứng dụng web React + TypeScript + Vite + Tailwind CSS.

## Cấu trúc
- `src/`: mã nguồn React
- `index.html`: entry point
- `vite.config.ts`: cấu hình Vite

## Chạy cục bộ
1. `npm install`
2. `npm run dev`
3. Truy cập `http://localhost:4173`

## Azure Static Web Apps
- Ứng dụng có thể triển khai trên Azure Static Web Apps.
- `build` tạo thư mục đầu ra tĩnh cho deploy.
